# 06. 화면 구조와 사용자 흐름

## 1. 정보 구조

```text
시작
  ├─ 이어하기
  ├─ 새 연대기
  ├─ 장수 열전
  ├─ 업적
  └─ 설정

캠페인
  ├─ 지도
  │   ├─ 도시 상세
  │   ├─ 군단 이동
  │   └─ 외교·정찰 정보
  ├─ 조정
  │   ├─ 장수 목록
  │   ├─ 관직·포상
  │   ├─ 인재 탐색·등용
  │   └─ 세력 성향
  ├─ 군단
  │   ├─ 군단 목록
  │   ├─ 편성
  │   └─ 전투 준비
  └─ 연대기
      ├─ 계절 기록
      ├─ 관계·칭호
      └─ 목표·승리 진행도
```

모바일 하단 내비게이션은 캠페인 중 `지도 / 조정 / 군단 / 연대기` 네 개로 고정한다.

## 2. 시작 화면

### 목적

사용자가 5초 안에 이어하기 또는 새 게임을 선택한다.

### 구성

- 로고와 부제
- `이어하기` — 저장이 있을 때 최우선 강조
- `새 연대기`
- 최근 캠페인 카드: 군주, 턴, 도시 수, 마지막 행동
- 장수 열전
- 업적
- 설정

### 상태

- 저장 없음: `이어하기` 숨김, 새 연대기 강조
- 저장 손상: 복구 안내, 원본 내보내기, 새 게임 선택
- 새 버전: 저장 마이그레이션 안내 후 진행

## 3. 새 연대기 흐름

### Step 1. 시나리오

MVP에서는 `천하각축` 하나만 활성화하고, 이후 시나리오는 잠금 카드로 예고한다.

표시:

- 한 줄 설명
- 도시·세력·최대 턴
- 역사 정확도: `가상 영웅집결`
- 예상 난이도

### Step 2. 군주

군주 카드:

- 초상
- 핵심 판타지
- 고유 효과 2개
- 시작 도시
- 시작 장수 3명 미리보기
- 운영 난이도

선택 시 `이 군주로 어떤 플레이를 하게 되는지` 2문장으로 설명한다.

### Step 3. 난이도와 보조 옵션

- 이야기 / 군웅 / 난세 / 천명
- 튜토리얼
- 정확한 확률 표시
- 전투 자동 넘김 여부
- 시드 직접 입력 또는 자동 생성

### Step 4. 최종 확인

- 군주
- 시나리오
- 난이도
- 시드
- 고유 효과
- `연대기를 시작한다`

## 4. 계절 보고 화면

턴 시작 시 전체 화면 카드로 한 번 표시한다.

### 우선 정보

1. 현재 계절·턴
2. 행동점 3
3. 금·군량 변화 예상
4. 국경 위험
5. 충성 경고
6. 복귀 군단·완료된 개발
7. 이번 턴 추천 목표 1~2개

### 예시

> **군웅력 4년 봄 · 7턴**  
> 낙양의 군량이 두 계절 안에 부족해질 전망입니다.  
> 원소군이 진류 북쪽에 병력을 모으고 있습니다.

버튼:

- `지도로 간다`
- `장수 경고 확인`
- `이번 턴 다시 보지 않기`

## 5. 캠페인 지도

### 상단 바

- 턴·계절
- 행동점
- 금
- 군량
- 명성
- 메뉴

자원을 누르면 이번 계절 예상 수입·지출을 보여준다.

### 지도 노드

도시 노드에는 다음만 즉시 표시한다.

- 소유 세력 문양
- 도시 이름
- 성벽 또는 위험 아이콘
- 주둔군 강약 3단계

정확한 숫자는 선택 후 하단 시트에서 표시한다.

### 군단 토큰

- 주장 얼굴 또는 깃발
- 병력 요약
- 이동 중 화살표
- 보급 경고

### 지도 모드

- 기본
- 외교 관계
- 군량·보급
- 위험도

MVP에서는 기본과 위험도만 먼저 구현한다.

## 6. 도시 상세 하단 시트

### 요약 탭

- 소유 세력
- 태수
- 농업·상업·치안·성벽
- 병력·군량
- 인접 도시
- 이번 턴 행동 가능 여부

### 행동 탭

- 개간
- 시장 정비
- 순찰
- 징병
- 훈련
- 성벽 보수
- 탐색

각 행동 카드에 표시:

- 행동점
- 자원 비용
- 예상 효과 범위
- 추천 담당 장수
- 실행 불가 이유

### 군사 탭

- 주둔군
- 군단 생성
- 이동
- 공격
- 원정 예상 군량

### 정보 탭

- 최근 사건
- 재야 인재 소문
- 적 정찰 정보
- 도시 특성

기본 카드:

- 초상·이름·역할
- 현재 임무
- 충성
- 피로
- 최고 능력치 2개

필터:

- 전체
- 내정
- 군사
- 대기
- 충성 낮음
- 부상

정렬:

- 통솔
- 무력
- 지력
- 정치
- 매력
- 충성
- 공적

### 장수 상세

- 능력치 오각형보다 숫자와 막대 우선
- 특성
- 병종 적성
- 인연
- 공적·칭호
- 충성 변화 이유

### 포상·관직

- 최대 3명 일괄 선택
- 예상 충성 변화
- 급여 변화
- 다른 장수의 불만 가능성

## 8. 탐색·등용 화면

### 탐색 전

- 대상 도시
- 담당 장수
- 발견 가능성
- 비용
- 소문 예시

### 발견 후

- 장수 실루엣 또는 공개 정도
- 관심사
- 예상 등용 난이도
- 추천 사절
- 선물·명분·관직 약속 선택

### 결과

성공:

> 서서는 당신이 백성을 대하는 방식을 지켜보았다. 그는 한동안 힘을 보태기로 했다.

실패:

> 아직 뜻을 정하지 못했다. 같은 방식으로 바로 다시 설득할 수는 없다.

실패해도 관계·정보가 남아 다음 시도의 전략이 생겨야 한다.

## 10. 군단 편성

### 3라인

```text
좌군       중군       우군
장수       장수       장수
병종       병종       병종
병력       병력       병력
```

모바일에서는 드래그만 요구하지 않는다.

- 빈 슬롯 누르기 → 장수 선택
- 장수 카드 누르기 → 위치 선택
- 좌우 교체 버튼
- 추천 편성

### 하단 요약

- 총병력
- 예상 군량
- 병종 상성 분포
- 주요 인연
- 활성 특성
- 약점 경고

## 11. 전투 준비

### 정보 순서

1. 목표 도시·지형
2. 적 정보 정확도
3. 아군·적군 전력 범위
4. 라인 편성
5. 진형
6. 책략
7. 후퇴 기준
8. 예상 위험

### 전투 시작 전 경고

- 군량 부족
- 중상 장수
- 조약 위반
- 병력 열세
- 성벽이 매우 높음
- 적 정보가 오래됨

경고 후에도 사용자가 강행할 수 있지만 결과를 이해하게 한다.

## 12. 전투 화면

### 상단

- 라운드 1/6
- 양측 총병력
- 사기
- 일시정지·속도 1×/2×/즉시 결과

### 중앙

- 좌·중·우 세 라인
- 장수 토큰
- 병력·사기 바
- 진형 연결선
- 책략·특성 작은 배지

### 하단 로그

한 번에 2~3줄만 강조하고 전체 로그 펼치기를 제공한다.

예:

> 장료의 `신속` 발동 — 우군이 먼저 움직입니다.  
> 기병이 궁병의 측면을 돌파했습니다.  
> 적 우군 사기 -12.

### 전투 중 선택

화면 전체를 가리지 않는 하단 선택 카드로 제공한다. 10초 제한 같은 실시간 압박은 MVP에서 사용하지 않는다.

## 13. 전투 결과

### 첫 화면

- 승리·패배·퇴각
- 잔여 병력
- 획득·손실
- 가장 큰 승패 요인 3개
- 최고 공적 장수

### 상세

- 라인별 결과
- 병종 상성
- 특성·책략 기여
- 포로·부상
- 연대기 등록 문장

### 다음 행동

승리:

- 입성
- 추격하지 않고 정비
- 포로 처리

패배:

- 귀환 도시
- 부상자 확인
- 다음 전투 개선 제안

즉시 유료 부활이나 광고는 없다.

## 14. 사건 화면

### 구성

- 장면 일러스트 또는 인물 초상
- 제목
- 짧은 도입
- 참여 장수의 조언
- 2~3개 선택지
- 선택지별 알려진 비용·방향

결과는 즉시 수치와 연대기 문장으로 보여준다.

숨겨진 지연 효과가 있어도 선택지 톤으로 위험을 암시한다.

### 외교 제안

## 17. 엔딩 화면

### 순서

1. 엔딩 제목
2. 천하 지도 변화
3. 군주 성향 결말
4. 핵심 장수 3~5명의 후일담
5. 캠페인 통계
6. 연대기 대표 장면
7. 다시 하기

공유 카드는 결과만 보여주며 저장 데이터·시드를 사용자가 선택하지 않으면 노출하지 않는다.

## 18. 설정

- 효과음
- 배경 음악
- 진동
- 애니메이션 감소
- 전투 속도
- 정확한 확률 표시
- 자동 저장 알림
- 튜토리얼 다시 보기
- 저장 내보내기·불러오기
- 캠페인 포기

캠페인 포기는 확인 문구를 직접 입력하게 하지 않고, 두 단계 확인과 저장 내보내기 선택을 제공한다.

## 19. 공통 상태 처리

### 로딩

- 빈 화면 대신 현재 작업 표시
- AI 생각 중 표시는 작은 상태 칩
- 지도 전체 차단 금지
- 1초 이상이면 진행 설명 표시

### 비어 있음

- 장수 없음: 탐색 안내
- 복귀 군단 없음: 군단 생성 안내
- 외교 대상 없음: 지도 확장 안내
- 연대기 없음: 첫 행동 유도

### 오류

- 사용자의 명령이 실패하면 이유와 해결법 제공
- 상태가 변경되지 않았음을 명확히 표시
- 재시도와 안전한 홈 복귀

### 확인 대화상자

다음에만 사용한다.

- 현재 캠페인 포기
- 조약 파기
- 군량 부족 강행
- 중상 장수 출전
- 중요한 포로 처리

일반 내정 행동마다 확인을 요구하지 않는다.

## 20. 첫 3턴 상세 흐름

### 1턴 — 도시를 살핀다

- 계절 보고
- 허창 선택
- 개간
- 순찰
- 장수 포상
- 결산

### 2턴 — 사람을 얻는다

- 재야 인재 소문
- 탐색 담당 선택
- 인재 발견
- 등용 제안
- 장수 상세·충성 안내

### 3턴 — 첫 전투

- 적 정찰
- 징병
- 군단 편성
- 병종 상성
- 진형 선택
- 전투
- 결과 원인 설명
- 포로 또는 사건

각 턴의 목표는 한 문장이고, 사용자가 다른 행동을 선택해도 진행을 막지 않는다.

## 21. 화면 완료 정의

화면은 예쁘게 보이는 것만으로 완료가 아니다. 다음을 만족해야 한다.

- 핵심 목적을 한 문장으로 설명 가능
- 정상·빈 상태·오류 상태 존재
- 모바일 360px에서 주요 행동 가능
- 키보드 접근 가능
- 로딩이 화면을 불필요하게 가리지 않음
- 게임 규칙을 UI 내부에서 다시 계산하지 않음
- 사용자 행동 결과가 연대기 또는 로그로 남음
