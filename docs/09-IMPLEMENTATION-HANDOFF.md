# 09. 수직 슬라이스 구현 인계

## 구현 상태

기획 문서의 첫 구현 게이트인 **3도시·2군주·12장수 수직 슬라이스**를 실제 플레이 가능한 정적 웹 게임으로 구현했다.

### 플레이 범위

- 군주 선택: 조조 / 유비
- 도시: 허창 / 진류 / 낙양
- 장수 12명
  - 조조군: 조조, 하후돈, 전위, 순욱, 곽가, 허저
  - 유비군: 유비, 관우, 장비, 조운, 서서, 미축
- 한 계절 행동점 3
- 도시 행동: 개간, 순찰, 징병, 인재 탐색
- 발견한 인재 등용
- 태수 임명
- 3라인 편성
- 병종: 보병 / 기병 / 궁병
- 진형: 어린진 / 방원진
- 책략: 무책 / 고무
- 최대 6라운드 결정적 자동 전투
- AI 세력 계절 행동
- 계절 사건 10개
- 연대기
- 수도 점령 또는 24턴 판정
- IndexedDB 자동 저장, localStorage 대체 저장
- JSON 저장 내보내기
- Web Audio 효과음
- 모바일 하단 메뉴와 계절 종료 바

## 기술 구조

```text
src/
  types.ts      # 직렬화 가능한 게임 상태와 데이터 타입
  content.ts    # 3도시·12장수·10사건 콘텐츠
  rng.ts        # seeded PRNG
  battle.ts     # 3라인 결정적 전투 엔진
  engine.ts     # 턴·내정·등용·AI·사건·승패
  storage.ts    # IndexedDB/localStorage 저장
  main.ts       # DOM UI와 화면 흐름
  styles.css    # 반응형 먹선 미니어처 UI
```

게임 결과에는 `Math.random()`을 사용하지 않는다. 캠페인 seed와 RNG cursor가 저장되므로 같은 상태·명령은 같은 결과를 만든다. 최초 seed 생성에만 브라우저 난수를 사용한다.

## 테스트

`npm test`는 TypeScript 빌드 후 Node 내장 테스트를 실행한다.

검증 범위:

- 초기 3도시·양 세력·행동점
- 도시 행동 비용과 효과
- 행동점 초과 거부
- 인재 탐색
- 전투 재현성
- AI 턴·수입·사건
- 사건 효과
- 출전 병력과 수비대 하한
- 조조·유비의 첫 진류 전투
- 첫 계절 AI 공격 유예
- 조조 승리 경로
- 유비 승리 경로

추가로 390×844 Chromium 모바일 스모크 테스트에서 다음 흐름을 확인했다.

```text
새 연대기 → 개간 → 진류 선택 → 출전 준비 → 전투 결과
→ 계절 종료 → 사건 선택 → 캠페인 계속
```

## 실행

```bash
npm install
npm test
npm run preview
```

`http://localhost:4173`에서 실행한다.

## 현재 의도적인 제한

- 전체 12도시·48장수 MVP는 아직 구현하지 않음
- 외교·첩보·포로·관직 체계는 축소 상태
- 장수 간 관계 사건은 일부 문장과 특성에만 반영
- 복수 저장 슬롯과 저장 가져오기는 미구현
- 장수 초상은 외부 이미지가 아닌 CSS 미니어처 임시 아트
- 전투 중 선택은 아직 없음
- AI는 수직 슬라이스용 규칙 기반이며 7세력 장기 계획은 다음 단계
