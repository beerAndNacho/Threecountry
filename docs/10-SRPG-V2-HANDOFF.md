# 10. SRPG V2 구현 인계

## 목적

기존 `main`의 군주 운영·자동전투 프로토타입과 분리하여, 사용자가 직접 장수를 편성하고 격자에서 이동·공격·기술을 지휘하는 스토리형 전술 게임을 `srpg-v2` 브랜치에 구축한다.

## 현재 구현한 수직 슬라이스

- 1장 `진류의 첫 깃발`
- 조조군 6명 중 4명 선택
- 조조, 하후돈, 전위, 순욱, 곽가, 허저
- 유비, 관우, 장비, 조운과 일반 부대 2개
- 12×8 전술 격자
- 초지, 길, 숲, 언덕, 마을, 지휘소, 다리, 하천
- 지형별 이동 비용·방어·회복
- 보병·기병·궁병·책사·호위 클래스
- 이동 후 공격, 사거리, 반격, 상성
- 장수별 고유 기술과 패시브
- 방어막, 기절, 이동 봉쇄, 공격·방어 강화
- 규칙 기반 적군 AI
- 유비 격파 또는 지휘소 점령 승리
- 12턴 제한
- 전투 전후 스토리 대화
- 출전 장수·순서·진입 전략 선택
- 병영·시장·군량창·군사부 운영
- 금·군량·명성 보상과 로컬 저장
- 독자적인 SVG/HTML SD 캐릭터 표현
- Web Audio 효과음, 외부 API 비용 없음

## 코드 구조

```text
srpg/
  index.html
  styles.css
  content.js   # 장수, 기술, 지형, 스토리, 시설
  engine.js    # 이동, 전투, 상태효과, AI, 승패
  app.js       # 화면·입력·저장·연출
  audio.js     # Web Audio 효과음
  tests/
    engine.test.mjs
  scripts/
    build.mjs
```

## 검증

`npm run build`는 모듈 로드 검사, JavaScript 문법 검사, 엔진 테스트, 정적 배포 파일 생성을 순서대로 수행한다.

고정 테스트:

- 아군 4명·적군 6명 생성
- 하천·점유 칸 이동 차단
- 이동 후 공격
- 같은 시드의 동일 피해
- 곽가 기술 피해·이동 봉쇄
- 하후돈 방어막·도발
- 적 AI의 즉시 공격
- 유비 격파 승리
- 적 지휘소 점령 승리
- 시설·진입 전략 능력치 반영

## 다음 우선순위

1. 모바일 실기기에서 격자 크기·하단 명령 패널 QA
2. 적 AI 턴 이동 애니메이션과 카메라 추적 개선
3. 전투 튜토리얼을 첫 3행동에 단계적으로 제공
4. 2장 낙양 전야와 신규 장수 등용
5. 장비·레벨·공적·부상 시스템
6. 장수 관계와 스토리 선택이 전투 배치에 미치는 효과
7. 클라우드 저장 전 로컬 다중 슬롯·내보내기

## 범위 경계

- 참조 이미지의 캐릭터·UI·배경·음악을 복제하지 않는다.
- 전술 격자, 편성, 이동·공격이라는 장르 문법만 참고한다.
- 온라인 PvP, 가챠, 행동력 판매, 유료 부활은 현재 범위에 포함하지 않는다.
