# Commercial Art Alpha v0.8.1

> 상태: **상용 품질 최종 통과 전 격리 검증판**

## 이번 단계

기존 픽셀·CSS 임시 토큰을 최종 표현에서 제거하고, 장수별 체형·얼굴형·눈매·수염·흉터·투구·갑옷·무기·자세가 다른 벡터 캐릭터 렌더러를 적용한다.

## 캐릭터 표현

- 조조·하후돈·전위·순욱·곽가·허저·유비·관우·장비·조운과 일반병 2종
- 대화용 180×220 반신 초상
- 전장용 120×140 SD 유닛
- 대기·보행·공격·기술·피격·방어·승리·퇴각 8개 상태
- 이동 시 6개 중간 키프레임
- 근접 베기·원거리·책략·피격 효과
- 장수별 아트와 동작을 한 화면에서 검수하는 모달

## 스토리 디렉터

1. 허창 군의 회의
2. 피난 행렬
3. 관우의 도전
4. 군량창 화재
5. 부상 장수의 결의
6. 진류 입성 후 첫 명령
7. 논공행상
8. 다음 장 진입로 선택

각 선택은 금·군량·명성, 장수 회복·버프·이동 봉쇄, 인의·지략·군율·결단 성향, 후속 분기 기록을 바꾼다.

## 현재 품질 판정

- 픽셀 표현 제거: 통과
- 장수 실루엣 분리: 1차 통과
- 모바일에서 작은 전장 유닛: 통과
- 이동 중간 프레임: 통과
- 8개 동작 상태: 구조 통과
- 최종 상용 일러스트: 미통과
- 손그림 수준의 세부 묘사·표정 다양성: 미통과
- 한 장 15~25분 콘텐츠: 미통과

따라서 v0.8.1은 `main` 승격 대상이 아니다. `commercial-alpha`와 별도 테스트 URL에서만 검증한다.
