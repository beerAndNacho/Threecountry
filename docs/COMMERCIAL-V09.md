# Cinematic Combat Alpha v0.9.0

> 상태: **상용 품질 최종 통과 전 격리 검증판**

## 목표

기존의 좌표 순간 변경과 큰 캐릭터 카드 중심 표현에서 벗어나, 작은 장수가 넓은 전장에서 실제 경로를 따라 움직이고 무기별 전투 동작·타격 효과·관계 스토리가 연결되는지 검증한다.

## 전투 표현

- 전장 기본 유닛 크기 축소, 선택한 장수만 확대
- 이동 경로를 8개 프레임으로 연결
- 이동 중 발밑 먼지와 보폭 움직임
- 검·쌍검·창·언월도·중량 무기·방패·활·책략 효과 분리
- 기술 사용 시 장수 컷인과 전용 대사
- 타격 정지, 카메라 흔들림, 검격·관통·책략·중량 충돌 효과
- 피해·회복 숫자
- 치명타·반격·퇴각·아군/적군 페이즈 배너
- 전장 전체 보기와 확대 보기
- 연출 강/절약 전환
- 런타임 FPS 표본과 최근 명령 메타데이터 노출

## 추가 스토리 8개

1. 하후돈의 창업 맹세
2. 곽가의 발열과 출전 여부
3. 마을 구조를 알리는 종
4. 장비의 호통에 대한 대응
5. 궁지에 몰린 관우 처리
6. 유비와 두 군주의 담판
7. 포로와 부상병 처리
8. 진류의 첫 야영과 다음 장 준비

기존 Story Director v2의 8개 장면과 합치면 현재 수직 슬라이스의 선택 장면은 총 16개다.

선택은 다음 항목을 바꾼다.

- 금·군량·명성
- 공격·방어·속도·보호막·기술력·이동 봉쇄
- 인의·지략·군율·결단
- 조조와 하후돈·곽가·전위·유비·관우의 관계
- 포로, 주민, 야영, 다음 장 진입 분기 플래그

## 자동 품질 게이트

- 신규 JavaScript 문법 검사
- 이동 중간 프레임 존재
- 무기별 효과와 기술 컷인 정적 검증
- 기본/선택 유닛 크기 차이 검증
- 관계·자원·전투 상태·분기 저장 검증
- 총 8개 신규 장면과 조건 분기 검증
- 기존 엔진 및 상용 알파 회귀 테스트 전체 통과

## 현재 판정

### 통과

- 픽셀 렌더러 제거
- 장수별 벡터 실루엣 1차 분리
- 전장 캐릭터 크기 축소
- 이동 중간 프레임과 무기별 효과 구조
- 10개 전투 상태와 기술 컷인
- 총 16개 선택 장면
- 관계 연대기와 전투 상태 반영

### 아직 미통과

- 전문 일러스트레이터 수준의 최종 얼굴·갑옷 묘사
- 손으로 그린 프레임 애니메이션 또는 리깅 기반 자연스러운 관절 움직임
- 15~25분 분량의 완결된 1장 콘텐츠
- 1,000회 자동 시뮬레이션과 장시간 모바일 성능 검증
- 캡처 이미지 직접 품질 검수

따라서 v0.9.0은 아직 `main` 승격 대상이 아니다. `commercial-alpha` 및 별도 테스트 URL에서만 검증한다.
