# Operation Campaign Alpha v1.0.0

> 상태: **판매 가능성 검증을 위한 격리 알파. main 승격 전 품질 게이트 진행 중.**

## 이번 단계의 목적

기존 수직 슬라이스가 한 번의 전투 후 끝나는 문제를 줄이고, 장수 성장·장비·스토리 선택이 여러 작전으로 이어지는 반복 플레이 구조를 검증한다.

## 제1장 작전 4개

1. `1-1 서쪽 난민로` — 정찰전
2. `1-2 마을의 종` — 구조전
3. `1-3 관우의 방진` — 정예전
4. `1-4 진류 본진 결전` — 장 결전

이전 작전을 최소 1성으로 완료해야 다음 작전이 열린다.

## 난이도

- 이야기: 아군 보정, 적 약화, 보상 90%
- 군웅: 표준 권장
- 난세: 적 공방 강화, 보상 125%
- 천명: 적 대폭 강화, 제한 턴 감소, 보상 155%

## 결과 평가

각 작전은 최대 3성을 받는다.

- 승리: 1성
- 기준 턴 이내: +1성
- 아군 4명 전원 생존: +1성

최고 별과 최고 턴은 저장되며 다음 작전 해금과 반복 도전에 사용된다.

## 실제 전투 반영

작전과 난이도는 다음 값을 직접 바꾼다.

- 제한 턴
- 적 최대 HP와 현재 HP
- 적 공격·방어·책략·속도
- 관우·장비·유비·조운 정예 보정
- 아군 시작 보호막
- 아군 시작 기술력
- 작전 완료 금·군량·명성 보상

## 자동 품질 게이트

- 기존 엔진·저장·성장·장비·캐릭터·스토리 회귀 테스트
- 작전 해금·별·보상·전투 스케일 정적 검증
- 결정적 자동 전투 1,000회
- 모든 전투가 제한 횟수 안에 종료되는지 검증
- 생존 유닛 좌표 중복·경계 이탈·비정상 HP 검증
- 승패가 한쪽으로 99% 이상 고정되는 파손 상태 검증

## 현재 판매 가능성 판정

### 통과한 부분

- 하나의 전투가 아닌 4개 작전 진행 구조
- 4단계 난이도와 보상 배율
- 작전별 적 스케일·제한 턴·정예 보정
- 별 평가·최고 기록·작전 해금
- 장수 성장·장비·16개 선택 장면과 연동 가능한 구조
- 1,000회 결정적 시뮬레이션 게이트

### 아직 미통과

- 전문 일러스트 수준의 최종 캐릭터 원화
- 3개 이상 서로 다른 전장 지도
- 최소 3시간 이상의 판매용 캠페인 분량
- 컨트롤러·키보드 전체 조작
- 다중 저장 슬롯과 클라우드 저장
- 실제 결제 상품에 필요한 이용약관·개인정보·지원 페이지
- 데스크톱·Android·iOS 장시간 플레이 QA

따라서 v1.0.0은 아직 판매판이 아니다. 반복 플레이와 자동 품질 검증 기반이 추가된 상용화 전 단계다.
