# Four Battlefields Alpha v1.1.0

> 상태: `commercial-alpha` 전용 상용화 검증판. main 승격 전.

## 변경 목적

v1.0.0의 작전 네 개가 같은 기본 지도를 반복하는 문제를 제거한다. 작전마다 지형·배치·날씨·전술 요구가 달라야 캠페인 진행이 단순 수치 증가로 느껴지지 않는다.

## 작전별 전장

### 1-1 진류 서쪽 난민로

- 새벽 안개
- 숲과 굽은 길
- 유민로와 마을
- 정찰대 각개 격파

### 1-2 동쪽 마을 방어선

- 봄비
- 두 마을과 두 개의 다리
- 관우·장비의 양면 압박
- 짧은 턴 안에 구조와 공격을 함께 판단

### 1-3 청룡 협곡

- 강풍
- 산과 숲이 둘러싼 좁은 중앙 통로
- 강화된 관우·장비 방진
- 측면 책략과 병종 상성 중심

### 1-4 진류 본진 외곽

- 저녁 연기
- 해자와 두 개의 교량
- 성문 안쪽 정예 배치
- 난세·천명 난이도에서 5턴 적 증원

## 구현 규칙

- 모든 전장은 12×8을 유지해 모바일 터치와 엔진 규칙을 재사용한다.
- 목표 칸은 항상 `camp` 지형이며 맵별 위치가 데이터로 검증된다.
- 플레이어와 적군 초기 위치는 전장별로 다르다.
- 진행 중인 기존 저장은 강제로 재배치하지 않고 다음 재도전부터 새 지도를 적용한다.
- 신규 전투는 작전·난이도 보정 이후 전장 데이터를 한 번만 적용한다.
- 증원은 고난도 본진 결전에서만 등장한다.

## 자동 검증

- 4개 맵 각각 8행×12열
- 목표 위치가 camp인지 확인
- 아군·적군 시작 위치 중복 금지
- 하천 등 이동 불가 지형 위 시작 금지
- 네 전장의 지형 지문이 서로 다름
- 네 전장의 배치 지문이 서로 다름
- 안개·비·강풍·연기 네 환경이 서로 다름
- 기존 44개 회귀 테스트와 1,000회 온보딩 시뮬레이션 유지

## 현재 상용화 판정

### 이번 단계 통과

- 반복 지도를 제거하고 작전별 전술 요구를 분리함
- 모바일 해상도를 유지하며 전장 다양성을 확보함
- 고난도 증원과 날씨 연출 기반을 추가함
- 전장 데이터 검증과 저장 호환 정책을 추가함

### 여전히 미통과

- 전문 원화 수준의 최종 인물 아트
- 세 장 이상 분량의 캠페인
- 3시간 이상 판매용 플레이타임
- 실제 유저 10명 이상의 블라인드 플레이 테스트
- 컨트롤러·키보드 전체 지원
- 다중 저장 슬롯과 클라우드 저장
- 상점 페이지·지원 정책·라이선스·개인정보 문서

따라서 v1.1.0 역시 판매판으로 선언하지 않는다. 다음 게이트는 다중 저장 슬롯, 튜토리얼, 전투 목표 다양화와 실제 장시간 플레이 검증이다.
