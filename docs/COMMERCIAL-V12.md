# Release Foundation Alpha v1.2.0

> 상태: `commercial-alpha` 전용. 판매판 선언 전 품질 검증 중.

## 이번 단계의 목적

장시간 캠페인에서 가장 치명적인 저장 유실과 신규 플레이어의 조작 이탈을 줄인다. 기능 데모가 아니라 실제 제품으로 운영하기 위한 저장·복구·온보딩 기반을 추가한다.

## 세 개의 독립 저장 슬롯

각 슬롯은 다음 상태를 함께 보관한다.

- 현재 화면과 진행 중 전투
- 금·군량·명성
- 시설 레벨
- 장수 레벨·경험치
- 보유 장비와 장착 상태
- 작전 해금·별·최고 턴
- 스토리 선택과 관계 기록
- 전투 연출 이벤트 상태

### 안정성

- 슬롯별 스냅샷 체크섬
- 손상된 슬롯은 안전한 빈 슬롯으로 정규화
- 슬롯 로드·삭제·가져오기 전 전체 상태 자동 백업
- 직전 상태 복구
- 세 슬롯 전체 JSON 내보내기·가져오기
- 활성 슬롯 약 4초 간격 자동 저장
- 페이지 숨김·종료 시 추가 저장
- 효과음·연출 강도 같은 전역 환경 설정은 슬롯 교체 시 유지

## 상황별 조작 안내

총 15단계가 실제 화면과 버튼에 연결된다.

1. 새 연대기
2. 스토리 진행
3. 작전 지도와 별
4. 시설 성장
5. 작전·난이도 선택
6. 장수 선택
7. 편성 확정
8. 초기 배치
9. 전투 시작
10. 장수 선택
11. 이동 명령
12. 이동 칸 선택
13. 공격·기술·방어
14. 턴 종료
15. 결과·보상

튜토리얼은 별도 슬라이드가 아니라 실제 조작 대상을 강조한다. 완료 위치와 종료 여부가 저장되며 언제든 `?` 버튼으로 다시 시작할 수 있다.

## 전장 표현 정합성

- 작전 카드에 실제 12×8 전장 축소 지도를 표시
- 배치 화면 미리보기를 선택한 작전의 실제 지형과 시작 위치로 교체
- 전투 화면·배치 화면·작전 카드가 같은 전장 데이터를 사용
- 전장·배치 지문을 브라우저 품질 검사에서 비교 가능하게 공개

## 자동 검증

- 슬롯 스키마·체크섬·요약 정보
- 변조된 백업 거부
- 손상 슬롯 안전 초기화
- 내보내기·가져오기·직전 백업 코드 경로
- 15단계 튜토리얼의 화면·실제 액션 연결
- 모바일 하단 안전 영역과 모션 감소
- 네 작전 썸네일과 배치 미리보기의 실데이터 연결
- 기존 전투·캐릭터·스토리·성장 회귀 테스트
- 1,000회 결정적 첫 작전 시뮬레이션

## 현재 판매 가능성 판정

### 이번 단계 통과

- 다중 로컬 저장 슬롯
- 자동 저장·백업·복구·가져오기·내보내기
- 실제 조작 기반 튜토리얼
- 작전 선택 화면과 배치 화면의 전장 일치
- 모바일 저장 관리 UI

### 여전히 미통과

- 전문 게임 원화 수준의 캐릭터 최종 아트
- 최소 3시간 이상의 캠페인
- 여러 장과 더 많은 세력·장수
- 실제 사용자 블라인드 테스트와 난이도 데이터
- 키보드·컨트롤러 전체 지원
- 클라우드 저장
- 상점 페이지·이용약관·개인정보·지원 정책
- Android·iOS·데스크톱 장시간 플레이 검증

v1.2.0은 판매판이 아니다. 저장 안정성과 첫 사용 경험이 추가된 출시 기반 알파다.
