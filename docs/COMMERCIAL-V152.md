# Commercial Alpha v1.5.2 — Tactical Battlefield

## 이번 품질 게이트

v1.5.2는 큰 인물 카드가 전장을 가리는 문제와 이동·공격 판단에 필요한 정보가 부족한 문제를 동시에 줄이는 전투 표현 단계다.

### 전장 미니어처

- 장수 프로필을 기반으로 얼굴형·체형·갑옷·투구·수염·흉터·안대·무기를 구분한다.
- 검·쌍검·창·장병기·방패·활·부채·죽간을 서로 다른 SVG 구조로 렌더링한다.
- 전장에서는 칸의 약 50~70% 크기로 표시하고 터치 영역은 칸 전체를 유지한다.
- 대기·보행·공격·기술·피격·방어·승리·퇴각 8개 상태를 갖는다.
- 이동 방향에 맞춰 좌우를 전환한다.

### 교전 예측

아군 장수를 선택하고 적을 누르면 다음 정보를 제공한다.

- 예상 피해 범위
- 명중률
- 치명타 확률
- 병종 우세·열세
- 적 지형의 방어·회피
- 반격 가능 여부

### 이동 경로

- 선택 장수와 포인터 위치 사이의 최단 경로를 표시한다.
- 숲·언덕의 추가 비용과 하천의 이동 불가를 반영한다.
- 다른 부대가 점유한 칸을 우회한다.
- 현재 이동력과 실제 경로 비용을 함께 표시한다.
- 이동 가능, 이동력 초과, 적 대상 경로의 색을 구분한다.

## 검증 항목

- Node 문법 검사
- 기존 전투·AI·스토리 회귀 테스트
- 미니어처·교전 예측·경로 모듈 단위 검사
- 390×844 모바일 Chromium 실제 플레이
- 전장 진입 및 아군·적군 생성
- 장수 4명 이상의 서로 다른 미니어처 확인
- 캐릭터 크기 상한 확인
- 경로 polyline과 비용 정보 확인
- 교전 예측 6개 지표 확인
- 가로 화면 넘침 없음
- 콘솔 오류·페이지 오류·요청 실패 없음

## 판정

전술 정보와 전장 가독성 게이트는 통과했다. 다만 최종 상용 아트 게이트는 아직 아니다. 다음 단계에서는 엔진 피해 공식과 예측 공식을 통일하고, 측면·배후·고저차를 실제 규칙으로 추가하며, 장수별 공격·피격 프레임을 더 세분화한다.
